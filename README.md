# WebGL Flappy Bird Game

An interactive browser game built with **JavaScript, WebGL, HTML5 and CSS3**. The project demonstrates real-time rendering, event-driven input handling, collision detection, score management and responsive browser interaction.

## Features

- WebGL rendering using custom vertex and fragment shaders
- Gravity-based bird movement and collision detection
- Keyboard, mouse and touch controls
- Current-score and high-score tracking
- Increasing game speed over time
- Sound effects for flap, collision and scoring
- Pause, restart and information controls
- Responsive canvas resizing

## Technologies

- JavaScript
- WebGL
- HTML5
- CSS3
- glMatrix

## Controls

- **Space / Up Arrow / Click / Touch:** flap
- **Left / Right Arrow:** horizontal movement
- **Pause:** pause the game
- **Restart:** reset the current run

## Run locally

No build system is required.

1. Clone or download the repository.
2. Open the project using a lightweight local HTTP server.
3. Open `index.html` in the browser through that server.

A local server is recommended because browsers may restrict some asset loading when HTML files are opened directly from disk.
